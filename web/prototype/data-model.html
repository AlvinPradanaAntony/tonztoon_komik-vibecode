Relasi logis dan catatan penting
  • profiles.id ↔ Supabase AuthRelasi identitas logis; bukan FK model Profile yang diperiksa.
  • library.user_id ↔ profiles.idUUID tanpa FK Profile pada model library yang diperiksa.
  • source_stats.source_name ↔ registry / comics.source_nameRelasi domain, bukan tabel master sources atau FK.
  • chapters.images adalah JSONB arrayBukan tabel images. images_are_invalid adalah generated field, baca saja.
  • Unique katalog(source_name, slug), (comic_id, chapter_number), (user_id, comic_id), (collection_id, comic_id).
  • Schema admin / sesi usulanactor/session UUID logis; resource polymorphic bukan FK bebas. Tidak ada token atau nilai row di diagram.
